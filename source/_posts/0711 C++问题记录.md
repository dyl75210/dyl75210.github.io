## 0711 C++问题记录

`priority_queue`（优先队列）是 C++ 标准库中的容器适配器，基于**堆数据结构**实现，用于高效管理按优先级排序的元素集合。以下是其核心特性和使用方法的系统总结：

------

### 📦 **一、核心概念与特性**

1. **数据结构**

   - 底层实现：默认使用`vector`作为容器，通过堆算法（大顶堆/小顶堆）维护元素优先级.

     堆类型：
   
     - 大顶堆（默认）：父节点值 ≥ 子节点值，队首元素为最大值（` std::less`）。
   
     - 小顶堆：父节点值 ≤ 子节点值，队首元素为最小值（`std::greater`）。
   
   - 时间复杂度：
   
     |   操作    | 时间复杂度 |         说明         |
     | :-------: | :--------: | :------------------: |
     | `push()`  |  O(log N)  | 插入元素并调整堆结构 |
     |  `pop()`  |  O(log N)  |     删除堆顶元素     |
     |  `top()`  |    O(1)    |     访问堆顶元素     |
     | `empty()` |    O(1)    |   检查队列是否为空   |
     | `size()`  |    O(1)    |     返回元素数量     |
   
2. **元素访问限制**

   - 仅能访问队首元素：通过`top()`获取优先级最高的元素，不支持随机访问或遍历（需逐次`pop()`取出）。


------

### ⚙️ **二、基本操作与定义**

#### **1. 定义方式**

```
#include <queue>
#include <functional> // 用于自定义比较器

// 默认大顶堆（最大堆）
priority_queue<int> max_heap;

// 显式定义小顶堆（最小堆）
priority_queue<int, vector<int>, greater<int>> min_heap;
```

#### **2. 常用成员函数**

```
max_heap.push(10);    // 插入元素
max_heap.pop();       // 删除堆顶元素
int top = max_heap.top(); // 获取堆顶元素
bool isEmpty = max_heap.empty(); // 检查是否为空
size_t count = max_heap.size();  // 获取元素数量
```

------

### 🎚️ **三、优先级设置方法**

#### **1. 基本数据类型**

- **大顶堆**：`priority_queue<int>` 或 `priority_queue<int, vector<int>, less<int>>`。

- 小顶堆：`priority_queue<int, vector<int>, greater<int>>`。


#### **2. 自定义类型（结构体）**

需通过**重载运算符**或**自定义比较器**定义优先级规则：

- **方法1：重载 `operator<`**（默认用于大顶堆）***函数体里一样则是默认，相反则逻辑相反。***

  ```
  struct Student {
      string name;
      int score;
      // 按分数降序（分数高者优先）
      bool operator<(const Student& s) const {
          return score < s.score; 
      }
  };
  priority_queue<Student> pq; // 大顶堆
  ```

- **方法2：自定义比较仿函数**（支持小顶堆）***默认 `<` 是大堆顶,  `>` 则相反***。

  ```
  struct CompareScore {
      // 按分数升序（分数低者优先）
      bool operator()(const Student& a, const Student& b) {
          return a.score > b.score; 
      }
  };
  priority_queue<Student, vector<Student>, CompareScore> min_pq;
  ```

> **注意**：比较器返回 `true` 时，表示第一个参数的优先级 ***<u>低于</u>***  第二个参数（即排在后面）。

------

### ⚡ **四、应用场景**

1. 任务调度：高优先级任务（如实时系统）优先执行。

2. 算法优化：

   - Dijkstra算法：用小顶堆快速选取最短路径节点。

   - Top-K问题：维护大小为 K 的小顶堆筛选最大/最小元素。

3. 事件处理：按时间戳或紧急程度排序事件。


------

### ⚠️ **五、注意事项与陷阱**

1. 临时对象生命周期：避免将临时容器绑定到引用（如`for (auto& x : create_temp_vector())`），可能导致悬垂引用。

2. 堆类型混淆：明确指定`std::greater`或`std::less`，避免默认行为不符合预期。

3. 空队列访问：调用`top()`或`pop()`前需用`empty()`检查，否则引发未定义行为。

4. 不支持遍历：需通过`while (!pq.empty()) { pq.top(); pq.pop(); }`逐个取出元素。


------

### 💎 **六、最佳实践**

1. 性能优化：

   - 对大型对象使用`const T&`传参避免拷贝。

   - 提前预留空间：`vector.reserve()`减少扩容开销。

2. 底层容器选择：

   - 默认`vector`效率最高，也可用`deque`，禁用 `list`（不支持随机访问）。

3. C++20 增强：

   - 使用`std::midpoint()`安全计算中位数。


------

### 🆚 **大顶堆 vs 小顶堆对比**

|   **特性**   | **大顶堆（`std::less`）** |        **小顶堆（`std::greater`）**        |
| :----------: | :-----------------------: | :----------------------------------------: |
| **队首元素** |          最大值           |                   最小值                   |
| **定义方式** |    `priority_queue<T>`    | `priority_queue<T, vector<T>, greater<T>>` |
| **典型应用** |   任务调度、最大值筛选    |          最短路径、Top-K最小元素           |
