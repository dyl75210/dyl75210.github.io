### 滑动窗口

滑动窗口可以归为快慢双指针，一快一慢两个指针前后相随，中间的部分就是窗口。**滑动窗口算法技巧主要用来解决子数组问题，比如让你寻找符合某个条件的最长/最短子数组**。

解决问题的关键：

1、弄清楚何时扩大窗口，何时缩小窗口。要解决这一点，需要设计合理的数据结构记录窗口中的数据，根据具体场景变通。如：用哈希表记录窗口中元素出现的个数，unordered_map<元素的类型,int>，int记录元素出现次数，每次右移出现一次++，左移退出一次--。注意：window.erase(s2[i-n]);  // 关键优化：移除计数为0的字符,不然会影响哈希表的相等判断，用数组就不会。将哈希表简化为vector的诀窍时将元素类型key值转换为数组的int类型索引i，比如26个小写字母char可以通过-‘a'的ASCLL值转换为0-25的int值。哈希集合记录无重复元素。

有了合理的数据结构，当window不满足要求时，就应该扩大窗口，此时就需要一个合理的判断条件。用数组存储的可以直接判断need和window是否相等，不等就继续扩大，相等就更新结果res。除了直接判断是否相等，另一种方法，就是**用一个valid记录在遍历时window和need相等的个数，如果个数等于need的大小，则证明window和need完全相等**。

满足要求，就应该缩小窗口，找最小need。缩小到不满足要求时停止。

2、何时记录结果。求第一个满足条件的需要在扩大窗口满足时记录结果；求最小need则需要在缩小窗口到不满足时更新结果，要比较每一次满足条件时的need的大小。求最长need则应该在扩大到不满足条件时，更新结果。

### KMP算法

    class Solution { public:    
    int strStr(string s, string p) {
    	vector<int> next(p.size() + 1, 0);  // next 数组
    	vector<int> res;		            // res数组:记录p在s中出现的位置下标
    	for (int j = 2, i = 0; j <= p.size(); j++) {
    	// 求next数组过程 next[j]就是字符串p的next数组
    		while (i > 0 && p[j - 1] != p[i]) i = next[i];//调用next数组，查找下一个比较点i。
    		if (p[j - 1] == p[i]) i++;
    		next[j] = i;        
    		}
            
    	for (int i = 0, j = 0; i < s.size(); i++) {
    	// p和s匹配的过程
    	while (j > 0 && s[i] != p[j]) j = next[j];//调用next数组，查找下一个比较点j。
    	if (s[i] == p[j]) j++;
    	if (j == p.size()) {
    	// 如果找到了一个匹配的位置
    		res.push_back(i - j + 1);   // 记录结果
    		j = next[j];    //调用next数组，查找下一个比较点j。        
    		}
    	}        
    	if (res.size() > 0)
    	return res[0];  // 题目要求返回第一个出现的位置        
    	return -1;    } };
