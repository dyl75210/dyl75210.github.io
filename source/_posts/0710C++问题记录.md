# C++11 基于范围的 for 循环详解

C++11 引入的基于范围的 for 循环（range-based for loop）简化了容器和数组的遍历语法，使代码更简洁、更安全。其核心语法为：

```
for (声明 : 表达式) {
    // 循环体
}
```

## 核心用法与示例

### 1. 遍历 STL 容器

```
std::vector<int> numbers = {1, 2, 3, 4, 5};

// 值拷贝方式遍历
for (int n : numbers) {
    std::cout << n << " "; // 1 2 3 4 5
}

// 引用方式遍历（避免拷贝，可修改元素）
for (auto& n : numbers) {
    n *= 2;
}
// numbers 变为 [2, 4, 6, 8, 10]

// 常引用方式遍历（只读，避免拷贝）
for (const auto& n : numbers) {
    std::cout << n << " ";
}
```

### 2. 遍历数组

```
int arr[] = {10, 20, 30, 40};

// 自动推断类型和数组大小
for (auto value : arr) {
    std::cout << value << " "; // 10 20 30 40
}
```

### 3. 遍历初始化列表

```
for (auto ch : {'A', 'B', 'C'}) {
    std::cout << ch; // ABC
}
```

## 底层机制（编译器展开）

基于范围的 for 循环会被编译器转换为传统的迭代器循环：

```
// 原始代码
for (declaration : expression) {
    statement;
}

// 编译器展开后
{
    auto&& __range = expression; // 获取范围引用
    auto __begin = begin(__range); // 获取起始迭代器
    auto __end = end(__range);     // 获取结束迭代器
    
    for (; __begin != __end; ++__begin) {
        declaration = *__begin;    // 解引用
        statement;                // 执行循环体
    }
}
```

## 关键特性详解

### 1. 类型推导

```
std::vector<double> prices = {2.99, 1.99, 3.49};

// 显式类型声明
for (double price : prices) { /* ... */ }

// 使用 auto 自动推导类型
for (auto price : prices) { /* ... */ } // price 类型为 double
```

### 2. 引用与拷贝对比

|    声明方式     |         优点         |         缺点         |
| :-------------: | :------------------: | :------------------: |
| `auto element`  |       简单直接       |     产生元素拷贝     |
| `auto& element` | 避免拷贝，可修改元素 | 可能意外修改容器内容 |
|  `const auto&`  |  避免拷贝，安全只读  |          -           |

### 3. 支持自定义容器

任何实现了 `begin()` 和 `end()` 的类型都可以使用：

```
class MyContainer {
    int data[5] = {1,2,3,4,5};
public:
    int* begin() { return &data[0]; }
    int* end() { return &data[5]; } // 尾后指针
};

MyContainer container;
for (auto n : container) {
    std::cout << n; // 12345
}
```

## 重要注意事项

### 1. 动态修改容器

**危险行为**（迭代器失效）：

```
std::vector<int> v = {1,2,3,4};

// 错误！可能导致迭代器失效
for (auto n : v) {
    if (n == 2)
        v.push_back(5); // 添加元素使迭代器失效
}
```

**安全修改方案**：

```
// 先收集要修改的位置
std::vector<size_t> indices;
for (size_t i = 0; i < v.size(); ++i) {
    if (v[i] == 2)
        indices.push_back(i);
}

// 稍后统一修改
for (auto i : indices) {
    v.insert(v.begin() + i, 99);
}
```

### 2. 临时范围表达式

```
// 返回临时对象（正确） auto n创建了vector中元素的拷贝，不依赖临时对象
for (auto n : createVector()) {
    // ...
}

// 错误！绑定到临时引用 auto&n 可能绑定到已经销毁的对象vector的元素的引用上
for (auto& n : createVector()) { // 临时对象生命周期问题
    // ...
}
```

### 3. 性能优化技巧

```
std::vector<std::string> largeVec(1000000, "test");

// 低效：拷贝大字符串
for (auto str : largeVec) { 
    // ...
}

// 高效：使用常量引用
for (const auto& str : largeVec) { 
    // ...
}

// C++17 起：结构化绑定
std::map<int, std::string> myMap;
for (auto& [key, value] : myMap) {
    key *= 2;
    // ...
}
```

## 与经典 for 循环对比

|    特性    |    基于范围的 for 循环     |    经典 for 循环     |
| :--------: | :------------------------: | :------------------: |
| 语法简洁度 |           ⭐⭐⭐⭐⭐            |          ⭐⭐          |
|   安全性   |   ⭐⭐⭐⭐⭐（自动边界检测）    | ⭐⭐（手动控制易出错） |
|   灵活性   |             ⭐⭐             |  ⭐⭐⭐⭐⭐（完全控制）   |
|  反向遍历  | 不支持（需用 rbegin/rend） |         支持         |
|  索引访问  |           不支持           |         支持         |
|  跳步遍历  |           不支持           |         支持         |

## 最佳实践总结

1. **优先使用基于范围的 for 循环**

   ```
   for (const auto& item : container) // 只读访问
   for (auto& item : container)       // 需要修改元素
   ```

2. **明确类型范围时避免使用 `auto`**

   ```
   // 更好：明确知道元素类型
   for (char c : str) 
   
   // vs
   for (auto c : str) // 类型不明确
   ```

3. **大型对象使用引用避免拷贝**

   ```
   struct BigData { /* ... */ };
   std::vector<BigData> bigVec;
   
   // 正确
   for (const BigData& data : bigVec)
   
   // 错误：产生大量拷贝
   for (BigData data : bigVec)
   ```

4. **需要索引时使用经典 for 循环**

   ```
   for (size_t i = 0; i < vec.size(); ++i) {
       if (i % 2 == 0) continue;
       vec[i] *= 2;
   }
   ```

5. **并发遍历使用并行算法（C++17+）**

   ```
   #include <execution>
   std::vector<int> v(1000);
   
   std::for_each(std::execution::par, v.begin(), v.end(), 
        [](auto& x) { x *= 2; });
   ```
   

**.和->的区别**

|     特性     |   `.`（点运算符）    |   `->`（箭头运算符）   |
| :----------: | :------------------: | :--------------------: |
| **操作对象** |  对象本身（非指针）  |     指向对象的指针     |
| **等效形式** |       直接访问       |    `(*ptr).member`     |
| **适用场景** | 栈对象、引用、值类型 |  堆对象指针、智能指针  |
| **内存安全** |       自动管理       | 需手动管理（原生指针） |
| **重载能力** |       不可重载       |  可重载（如智能指针）  |

**三元条件运算符 `? : `**

- 语法：`条件 ? 表达式1 : 表达式2`

- 先判断条件，为真则返回表达式1的值，否则返回表达式2的值
